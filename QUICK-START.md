## 🚀 Installation (2 Minutes)

### Method 1: WordPress Admin (Easiest)

1. **Zip the theme folder**
   ```bash
   # On your computer, zip this entire folder
   # OR use this command if on Linux/Mac:
   zip -r aro-theme.zip ARO-WordPress-Theme/
   ```

2. **Upload to WordPress**
   - Go to your WordPress admin: `Appearance > Themes`
   - Click `Add New` → `Upload Theme`
   - Choose the ZIP file
   - Click `Install Now`
   - Click `Activate`

3. **Done!** 🎉 Your theme is live!

### Method 2: FTP/File Manager

1. **Upload the folder**
   - Upload the entire `ARO-WordPress-Theme` folder to:
   - `/wp-content/themes/`

2. **Activate**
   - Go to `Appearance > Themes`
   - Find "ARO Glassmorphism Theme"
   - Click `Activate`

## ⚙️ Quick Setup (5 Minutes)

### Step 1: Install Recommended Plugins
```
✅ WooCommerce (for products/shop)
✅ Elementor (for page building)
✅ Contact Form 7 (optional, for contact forms)
```

### Step 2: Configure Theme
1. Go to `Appearance > Customize`
2. Set your:
   - Hero section content
   - Theme colors
   - About section text
   - Footer copyright
   - Social media links

### Step 3: Create Menu
1. Go to `Appearance > Menus`
2. Create a new menu
3. Add pages: Home, Shop, Women, Men, Blog, About
4. Assign to "Primary Menu"
5. Save

### Step 4: Set Homepage
1. Go to `Settings > Reading`
2. Select "A static page"
3. Create a page called "Home"
4. Set it as homepage

### Step 5: Add Products (WooCommerce)
1. Create categories: "Women" and "Men"
2. Add products to these categories
3. They'll automatically appear in the sliders!

## 🐛 Troubleshooting

### Sliders not working?
- Make sure GSAP loaded (check browser console)
- Clear cache

### Styles look wrong?
- Clear browser cache
- Clear WordPress cache
- Regenerate CSS in Elementor

### Products not showing?
- Check WooCommerce is installed
- Verify products have correct categories
- Make sure products are published
