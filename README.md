# ARO Glassmorphism WordPress Theme

![Version](https://img.shields.io/badge/version-3.7-blue.svg)
![WordPress](https://img.shields.io/badge/WordPress-6.0+-green.svg)
![Elementor](https://img.shields.io/badge/Elementor-Compatible-orange.svg)
![PHP](https://img.shields.io/badge/PHP-7.4+-purple.svg)

A premium glassmorphism WordPress theme with Elementor support, featuring minimal luxury design with deep plum and gold accents. Perfect for fashion and e-commerce websites.

## 🎨 Features

- **Glassmorphism Design**: Modern, translucent UI elements with backdrop blur effects
- **Elementor Compatible**: Full support for Elementor page builder
- **WooCommerce Ready**: Complete e-commerce functionality
- **Product Sliders**: Interactive GSAP-powered product carousels with drag/swipe support
- **Responsive Design**: Mobile-first approach, works on all devices
- **RTL Support**: Full right-to-left language support (perfect for Persian/Arabic)
- **Custom Animations**: Smooth fade-up animations and interactive elements
- **Theme Customizer**: Easy customization through WordPress Customizer
- **Performance Optimized**: Lightweight and fast-loading
- **SEO Friendly**: Clean, semantic HTML5 markup

## 📋 Requirements

- WordPress 6.0 or higher
- PHP 7.4 or higher
- WooCommerce 7.0+ (recommended for product features)
- Elementor (optional, for advanced page building)

## 🚀 Installation Instructions

### English Instructions

#### Method 1: Upload via WordPress Admin

1. **Download the Theme**
   - Download or clone this repository
   - If cloned, zip the entire theme folder

2. **Upload to WordPress**
   - Log in to your WordPress admin panel
   - Navigate to `Appearance > Themes`
   - Click `Add New` button at the top
   - Click `Upload Theme`
   - Choose the theme ZIP file
   - Click `Install Now`

3. **Activate the Theme**
   - After installation, click `Activate`
   - Your theme is now active!

#### Method 2: FTP/File Manager Upload

1. **Download the Theme**
   - Download or clone this repository

2. **Upload via FTP**
   - Connect to your server via FTP
   - Navigate to `/wp-content/themes/`
   - Upload the `ARO-WordPress-Theme` folder
   - Ensure all files are uploaded completely

3. **Activate from WordPress**
   - Log in to WordPress admin
   - Go to `Appearance > Themes`
   - Find "ARO Glassmorphism Theme"
   - Click `Activate`

## ⚙️ Configuration

### Initial Setup

1. **Install Required Plugins** (Optional but Recommended)
   ```
   - Elementor (for advanced page building)
   - WooCommerce (for e-commerce features)
   - Contact Form 7 (for contact forms)
   ```

2. **Configure Theme Settings**
   - Navigate to `Appearance > Customize`
   - Configure:
     - Hero Section (title, description, image)
     - About Section
     - Theme Colors (primary and accent colors)
     - Footer settings
     - Social media links

3. **Setup Menus**
   - Go to `Appearance > Menus`
   - Create a new menu
   - Assign it to "Primary Menu" location
   - Add your pages/links

4. **Configure WooCommerce** (if using e-commerce)
   - Go to `WooCommerce > Settings`
   - Complete the setup wizard
   - Add your products
   - Create product categories: "Women" and "Men" for the sliders

5. **Setup Widgets** (Optional)
   - Go to `Appearance > Widgets`
   - Configure Footer Widget areas (1-4)
   - Add your widget content

### پیکربندی اولیه (فارسی)

۱. **نصب افزونه‌های مورد نیاز** (اختیاری اما توصیه می‌شود)
   ```
   - Elementor (برای ساخت صفحات پیشرفته)
   - WooCommerce (برای قابلیت‌های فروشگاهی)
   - Contact Form 7 (برای فرم‌های تماس)
   ```

۲. **تنظیمات قالب**
   - به `ظاهر > سفارشی‌سازی` بروید
   - تنظیمات زیر را پیکربندی کنید:
     - بخش هیرو (عنوان، توضیحات، تصویر)
     - بخش درباره ما
     - رنگ‌های قالب (رنگ اصلی و رنگ تأکیدی)
     - تنظیمات فوتر
     - لینک‌های شبکه‌های اجتماعی

۳. **ساخت منو**
   - به `ظاهر > منوها` بروید
   - منوی جدیدی ایجاد کنید
   - آن را به موقعیت "Primary Menu" اختصاص دهید
   - صفحات/لینک‌های خود را اضافه کنید

۴. **پیکربندی ووکامرس** (در صورت استفاده از فروشگاه)
   - به `WooCommerce > تنظیمات` بروید
   - راهنمای نصب را کامل کنید
   - محصولات خود را اضافه کنید
   - دسته‌بندی‌های محصولات "Women" و "Men" را برای اسلایدرها ایجاد کنید

۵. **ابزارک‌ها** (اختیاری)
   - به `ظاهر > ابزارک‌ها` بروید
   - ناحیه‌های ابزارک فوتر (۱-۴) را پیکربندی کنید
   - محتوای ابزارک‌های خود را اضافه کنید

## 🎯 Creating Your Homepage

### Using the Built-in Front Page

The theme includes a pre-built front page template (`front-page.php`) that displays:
- Hero section with customizable content
- Women's product slider
- Men's product slider
- New arrivals grid
- Blog/journal section
- About section

To use it:
1. Go to `Settings > Reading`
2. Select "A static page" under "Your homepage displays"
3. Create a new page titled "Home"
4. Select it as the homepage
5. Save changes

### Using Elementor

For more customization:
1. Install and activate Elementor
2. Create a new page
3. Click "Edit with Elementor"
4. Build your custom homepage
5. Set it as the homepage in `Settings > Reading`

The theme includes Elementor-compatible widgets (coming in future updates):
- ARO Product Slider
- ARO Hero Section
- ARO Blog Feed
- ARO Product Grid

## 📱 Customizing Content

### Hero Section
- **Location**: `Appearance > Customize > Hero Section`
- Customize:
  - Badge text
  - Main title
  - Description
  - Featured image
  - Image caption
  - Rating badge

### Colors
- **Location**: `Appearance > Customize > Theme Colors`
- Change:
  - Primary color (default: Mulberry #8A2F56)
  - Accent color (default: Gold #C8A45D)

### Footer
- **Location**: `Appearance > Customize > Footer Settings`
- Customize:
  - Copyright text
  - Social media links (Facebook, Instagram, YouTube, LinkedIn, Twitter)

## 🛍️ Setting Up Products

1. **Install WooCommerce**
   - Go to `Plugins > Add New`
   - Search for "WooCommerce"
   - Install and activate

2. **Add Products**
   - Navigate to `Products > Add New`
   - Add product details
   - Set featured image
   - Add to categories (Women/Men)
   - Add custom attributes:
     - Material (e.g., "Wool / Linen Blend")
     - Season (e.g., "SS25")

3. **Product Categories**
   - Create categories: "Women" and "Men"
   - These will populate the sliders on the homepage

## 🎨 Shortcodes

### Product Slider
Display a product slider anywhere:
```php
[aro_product_slider category="women" count="20"]
```

Parameters:
- `category`: Product category slug (e.g., "women", "men")
- `count`: Number of products to display (default: 20)

## 🎭 Styling & Customization

### CSS Variables
The theme uses CSS custom properties for easy customization:

```css
:root {
  --aro-primary: #8A2F56;  /* Primary color (Mulberry) */
  --aro-accent: #C8A45D;   /* Accent color (Gold) */
  --aro-bg-start: #0A0A0B; /* Background gradient start */
  --aro-bg-mid: #111113;   /* Background gradient middle */
  --aro-bg-end: #0C0C0E;   /* Background gradient end */
}
```

### Custom CSS
Add custom CSS via:
1. `Appearance > Customize > Additional CSS`
2. Or create a child theme

## 🐛 Troubleshooting

### Common Issues

**Sliders not working:**
- Ensure GSAP is loaded (check browser console)
- Clear cache and refresh
- Check for JavaScript errors

**Styles not applying:**
- Clear browser cache
- Clear WordPress cache
- Regenerate CSS in Elementor (if using)

**Products not showing in sliders:**
- Ensure products have correct categories
- Check that WooCommerce is installed
- Verify products are published
